# Documentacion tecnica (es)

Este directorio contiene documentacion funcional y tecnica del proyecto INNO_TRACK.

## Contenido inicial

- [arquitectura-sistema.md](./arquitectura-sistema.md): arquitectura general, flujo de datos, permisos y puntos de entrada.
- [api-resumen.md](./api-resumen.md): resumen de endpoints REST agrupados por modulo.

## Objetivo

Esta primera version busca crear una base comun para que el equipo pueda:

- Entender la estructura del sistema sin recorrer todo el codigo.
- Ubicar rapidamente donde vive cada responsabilidad.
- Continuar documentando por capas (modelos, serializers, paginas y pruebas).

## Convencion recomendada

Para siguientes documentos:

- Escribir en espanol.
- Evitar describir detalles no existentes en el codigo.
- Incluir fecha de actualizacion y alcance del documento.
